# Custom Creatives 💜

Loja de produtos personalizados feitos com impressão 3D.

## Catálogo

12 produtos, com acessórios gamer, suportes, vasos, brinquedos articulados, chaveiros e marcadores de página.

## Regra de preço

R$ 1,00 por grama para produtos simples. Os pesos precisam ser confirmados no fatiador antes de aceitar pagamentos reais; personalizações podem exigir orçamento.

## Funcionalidades em teste

- Catálogo responsivo com cores
- Carrinho de compras
- Área de personalizados
- Instruções para Pix e conferência manual

## Importante

Protótipo estático: não há backend, login seguro de administrador, confirmação automática de Pix ou armazenamento de pedidos no servidor. **Não colocar a loja para receber pagamentos reais sem finalizar essas integrações.** Verifique os direitos de uso comercial dos modelos 3D.

## Rodar localmente

Abra `index.html` no navegador.
